# Project Overview

Questify is a desktop task management application with a medieval RPG-inspired design (Skyrim-style). Built as an Electron desktop app with cloud synchronization, featuring a gamified experience system where completing tasks rewards experience points (XP) and levels up your character. The app includes AI-powered task difficulty estimation and supports multilingual interfaces.

# Technologies Used

## Core
- **Electron** - Cross-platform desktop application framework
- **React 18** - UI library
- **TypeScript** - Type-safe JavaScript
- **Vite** - Build tool and development server

## UI & Styling
- **Tailwind CSS** - Utility-first CSS framework
- **Material-UI (@mui/material)** - React component library
- **FontAwesome** - Icon library
- **Pixi.js** - 2D WebGL renderer for graphics

## Backend & Data
- **Firebase / Firestore** - Cloud database and authentication
- **Firebase Auth** - User authentication system

## Features
- **i18next / react-i18next** - Internationalization (multilingual support)
- **react-beautiful-dnd** - Drag and drop functionality for task reordering
- **OpenAI API** - AI-powered task difficulty calculation (1-10 scale)
- **Howler** - Audio library for sound effects
- **electron-builder** - Application packaging and distribution
- **electron-updater** - Automatic update system

# Features

- User authentication (Sign up / Log in) with Firebase
- Cloud data synchronization with Firestore
- Task management (add, edit, complete, delete tasks)
- Gamified leveling system with XP rewards
- AI-powered difficulty estimation for tasks
- Category creation and filtering
- Drag and drop task reordering
- Multilingual interface support
- System tray integration
- Always-on-top window option
- Automatic update notifications
